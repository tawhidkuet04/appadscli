The gap every tool leaves open

ASO tools can't manage ads. Ads tools can't see organic. appadscli fuses both.

Apple's demand data

The Ads API is the only source of Apple's own numbers: search-term popularity (1–5), impression share, suggestions, recommendations. Tools resell this — appadscli insights popularity gives it to you free, through your own credentials.

Organic outcomes

The iTunes Search API shows what actually ranks. appadscli snapshots your keywords on a schedule into local SQLite — aso track report for history, aso track alerts to fail CI when ranks drop.

Workflows, not wrappers

The loops that actually grow an app, encoded.

01 · harvestSearch terms in, profit out.

Discovery campaigns mine what users really type. appadscli reads the search-terms report and:

  • promotes converting terms to exact match — bid seeded from observed CPT
  • negates them in discovery so campaigns never compete
  • negates the terms burning money with zero installs
  • remembers every promotion — a term is never promoted twice
$ appadscli harvest run --discovery 74130 --target 74131 \ --min-installs 2 --max-cpa 3.00 --auto-negate --dry-run [ { "action": "promote", "searchTerm": "habit streak app", "installs": 6, "cpa": 1.82, "bid": 1.21, "reason": "6 installs at 1.82 CPA — promote to exact" }, { "action": "negate-waste", "searchTerm": "free habit games", "taps": 41, "installs": 0, "spend": 38.70 } ]

02 · autonomy with a leashAlert → propose → auto.

Black-box automation is why indies distrust ad tools. appadscli's watch tick runs from cron, evaluates your guardrails — CPA breaches, spend anomalies, rank drops, harvest candidates — and escalates only as far as you allow. Proposals land as plan files you review like a pull request.

$ appadscli watch --config guardrails.json → plan written to appadscli-plan-20260815.json $ appadscli plan show appadscli-plan-20260815.json 2 change(s): 1. pause campaign discovery-us — CPA breach: spend 41.20, installs 3 (limit 3.00) 2. negate wasteful term: "free habit games" $ appadscli plan apply appadscli-plan-20260815.json --confirm

03 · agent-nativeBuilt for hands and for agents.

JSON-first output, a built-in MCP server exposing 32 tools, and an installable skills pack that teaches agents the playbooks — not just the flags. Mutating tools without confirm: true run as dry-runs: an agent must show you the plan before it can spend a cent.

$ claude mcp add appadscli -- appadscli mcp serve $ appadscli install-skills ✓ installed 3 skill file(s) to .claude/skills · harvest-playbook — the promotion loop, safely · launch-playbook — research → scaffold → seed → track · audit-playbook — find wasted spend, read-only

Safety invariants
Dry-run everythingEvery mutating command supports --dry-run; spending requires --confirm.
AuditedAll mutations logged locally; history verify cross-checks Apple's change history.
Keychain-firstCredentials in the macOS keychain or 0600 files. Never in configs, never phoned home.
No telemetryTraffic goes to Apple's API and nowhere else. It's your account and your data.
